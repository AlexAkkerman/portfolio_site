## Image Rendering Bug
**Issue:** Over 40 images in `/photo/film/` render as raw HTML code (`<div dir='auto'>абстракция</div>`) instead of displaying images.

**Root Cause:** The `alt` attribute in `src/data.ts` contains HTML markup (`<div dir='auto'>...text...</div>`) instead of plain text. Browsers interpret this literal string as the alt text.

**Fix Required:** Replace HTML div structures with simple UTF-8 encoded filenames/text in the `alt` attribute.
