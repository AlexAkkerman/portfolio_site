# Как добавить реальные фотографии на сайт

## Шаг 1: Собрать фото

Собери свои пленочные (film) и цифровые (digital) фотографии на компьютере.

## Шаг 2: Поместить в папки

```
public/photo/film/       # Пленочные фото
public/photo/digital/    # Цифровые фото
```

**Название файлов:** Используйте простые названия без пробелов, например:
- `1.jpg` или `portrait_01.jpg`
- `street_02.jpg`
- `city_sunset_03.jpg`

## Шаг 3: Обновить data.ts

Отредактируйте файл `src/data.ts` и добавьте свои фото в массив `photos`:

```typescript
{
  id: "f1",
  src: "/photo/film/1.jpg",       // или "portrait_01.jpg"
  alt: "Портрет пленочным фото",
  type: "film",
},
```

**Для цифровых фото:**

```typescript
{
  id: "d1",
  src: "/photo/digital/1.jpg",
  alt: "Уличный снимок",
  type: "digital",
},
```

## Шаг 4: Перезагрузить сайт

В браузере нажмите `Ctrl + F5` для полной перезагрузки.

---

**Совет:** После загрузки фото в папки, откройте браузер и обновите страницу — фотографии появятся автоматически! 📸
